                                         项目名称：基于C++实现的分布式网络通信框架

项目描述：本项目自主实现了分布式环境下本地服务在RPC节点上的注册、发布与远程调用功能，完成了自定义通信协议、服务注册中心、日志系统及高并发网络模型，具备高性能和良好的扩展性。

主要工作：

1、解决TCP粘包问题，通过自定义消息格式、编解码器实现数据完整传输；

2、使用Protobuf实现数据的高效序列化和反序列化，保证数据传输的规范性和性能；

3、使用Zookeeper作为服务注册中心和配置中心，实现服务注册与发现功能，提供服务器的IP和端口信息给客户端；

4、引入Watcher机制监听Zookeeper节点变化，动态感知服务上线/下线，保证服务的高可用性以及实时更新；

5、集成日志库，实现线程安全的日志功能，帮助开发者快速定位和诊断RPC服务问题；

6、基于Muduo Reactor网络模型实现网络层，完成网络IO与RPC方法调用的解耦设计，提升代码可维护性和系统并发性能。

个人收获：深入理解分布式RPC架构的核心原理，掌握服务注册与发现的完整流程；掌握Zookeeper的应用场景、节点监听及配置管理，增强对分布式协调服务的理解；熟练使用Muduo网络库，实现高并发网络通信，提升了对网络编程的理解和实践能力；提升在C++网络通信、分布式架构和日志系统设计等方面的开发能力。
